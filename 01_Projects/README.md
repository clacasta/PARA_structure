# 01 — Projects

Aquí van los **proyectos en curso**, entendidos como un resultado concreto con fecha de fin.

Una nota por proyecto. Una nota por objetivo / outcome.

- `01_Projects/<nombre-del-proyecto>/`
    - `README.md` — objetivo, criterios de "hecho", enlaces a Areas/Resources implicadas, deadline
    - `tasks.md` — checklist viva (to-do / doing / done)
    - `notes.md` — bitácora de decisiones, reuniones, enlaces relevantes

**Criterio PARA:** si tiene deadline y produce un outcome claro → Project. Si no tiene deadline claro → Area.
