# 02 — Areas

Aquí van las **áreas de responsabilidad y estándares** que quieres mantener a lo largo del tiempo.

No tienen fecha de fin; viven mientras la responsabilidad exista.

- `02_Areas/<area>/`
    - `README.md` — alcance, criterios de salud de la área
    - `checklists.md` — revisiones periódicas (semanal / mensual / trimestral)
    - `notes.md` — observaciones, problemas recurrentes

**Criterio PARA:** si tienes que mantenerlo "bien" durante meses/años → Area.
