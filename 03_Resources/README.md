# 03 — Resources

Aquí van los **temas de interés y materiales de referencia** que usas cuando algo lo requiere.

No son proyectos activos ni áreas de responsabilidad; son conocimiento disponible para el futuro.

- `03_Resources/<tema>/`
    - `README.md` — qué cubre este tema, índice de subcarpetas
    - `links.md` — bookmarks curados con una frase de utilidad
    - `notes.md` — extractos, resúmenes, ideas

**Criterio PARA:** si es un tema que te interesa y puede alimentar un Project o un Area futuro → Resource.
